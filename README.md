# Concert Festival Management System
The Concert Festival Management System developed by **Team A**.  

The system manages the main operations of a music festival, including *ticket management, vendor management, stage scheduling, and performer information*

## Project Objectives

The main objectives of this project are to:

- Develop a concert festival management system to organize and track all related information.
- Apply logical thinking and software engineering principles.
- Practice *teamwork, version control, Test-Driven Development and collaborative development using Git and GitHub*.

## System Components


### 1. Ticket Management
**Main responsibilities:**
- Display available ticket categories and seatmap
- Manage ticket information and price.
- Handle ticket registration and purchases.
- Provide event cards according to the purchased ticket category
- Manage card benefits, bonus points, and discount vouchers

### 2. Vendor Management
**Main responsibilities:**
- Display vendor information.
- Manage vendor registration.
- Organise vendor categories.
- Manage vendor transactions and payment information.

### 3. Stage Management
**Main responsibilities:**
- Display available stages.
- Manage stage information.
- Organise performance schedules.
- Prevent scheduling conflicts.
- Provide a dashboard about the festival

### 4. Performer Management
**Main responsibilities:**
- Display performer information.
- Manage performer profiles.
- Organise performer lineups.
- Assign performers to stages and schedules.
- Provide a run-time clock during the event to track timeline
